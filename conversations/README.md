# Saved conversations

Use this folder for chat exports or copies of Cursor agent session logs you want to keep **in the repository**.

**Agent transcripts (JSONL):** Cursor writes these under your user config, not in the repo, for example:

`~/.cursor/projects/Users-lynnfrank-src-minecraft-3d-viewer/agent-transcripts/`

Copy or move `.jsonl` files from there into this directory if you want them versioned or backed up with the project. Composer chat history is managed in the Cursor UI; use whatever export or copy workflow Cursor provides if you need those here too.
